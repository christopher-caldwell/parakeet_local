# Local data boundary

Local imports, decoding, ASR, diarization, embeddings, and benchmarks never send recording content to a service. Dependency and explicitly requested model downloads are allowed. Media retrieval is an explicit URL operation. AI enhancement requires both an enabled profile and explicit authorization of its declared local/remote subprocess route; neither installation nor normal dictation grants consent. Profiles use bundle IDs and no approved prompt text is fabricated.

Keep `.local/`, `.references/`, models, private exports, recordings and derived clips out of Git. Diagnostics should favor counts/timings over transcript content. Speaker vectors stay local and are excluded from AI transformation input. Originals are opened read-only and never migrated or repaired.

Clipboard fallback snapshots a single item's eagerly readable typed data (at most 64 types/16 MiB) before temporarily replacing it. Multiple items, unreadable promised data and oversized snapshots are refused. A 0700 per-data-root recovery directory holds 0600 journals while insertion is in flight; these may contain unrelated clipboard data and must remain private. A unique paste marker and change generation prevent restoring over a newer copy. Recovery restores only an owned interrupted transaction or discards its obsolete snapshot; an inert private marker remains beside restored types for crash safety. A per-user lock serializes paste/recovery across application data roots. Unknown pending transactions from another root are refused. Journals are removed on successful restoration or when the clipboard has changed elsewhere. No clipboard data is logged or sent to AI.

Use `dictation recover-clipboard` or the Dictation recovery button after an interrupted insertion. Desktop startup also attempts recovery. If paste delivery cannot be verified, the raw transcript remains available and the target must be inspected before retrying; a timeout is not proof that no paste occurred. Actual fallback delivery/editor compatibility still needs verification.
